macOS Magnet 快捷键与窗口隐藏技巧

Magnet 是一款 macOS 窗口管理工具，可以通过快捷键快速完成左右分屏、四分屏、三分屏和跨显示器移动。

本文整理我日常使用的 Magnet 快捷键，以及为什么我更喜欢使用 ⌘H + ⌘Tab 隐藏和恢复窗口，而不是 ⌘M 最小化。

Magnet 常用快捷键

Magnet 的快捷键可以自定义，下面记录的是默认配置。

半屏、最大化和居中

功能 快捷键
左半屏 ⌃ Control + ⌥ Option + ←
右半屏 ⌃ Control + ⌥ Option + →
上半屏 ⌃ Control + ⌥ Option + ↑
下半屏 ⌃ Control + ⌥ Option + ↓
最大化 ⌃ Control + ⌥ Option + Enter
居中 ⌃ Control + ⌥ Option + C
恢复原始大小和位置 ⌃ Control + ⌥ Option + Backspace

日常开发先记住下面三个即可：

这三个快捷键基本可以覆盖 IDE、终端和浏览器的窗口布局。

四分屏

可以把 U I J K 记成键盘上的 2 × 2 方格：

左上 ⌃⌥U 右上 ⌃⌥I
左下 ⌃⌥J 右下 ⌃⌥K

三分屏

功能 快捷键
左侧 1/3 ⌃⌥D
右侧 1/3 ⌃⌥G
左侧 2/3 ⌃⌥E
右侧 2/3 ⌃⌥T

多显示器

功能 快捷键
移到上一个显示器 ⌃⌥⌘←
移到下一个显示器 ⌃⌥⌘→

隐藏窗口比最小化更顺手

macOS 的“隐藏”和“最小化”行为不同：

操作 快捷键 切回来时的表现
隐藏当前 App ⌘H 使用 ⌘Tab 切回 App，窗口会直接重新显示
最小化当前窗口 ⌘M 使用 ⌘Tab 只能切回 App，窗口不一定恢复
关闭当前窗口或标签页 ⌘W 关闭窗口，但不会像 ⌘Q 一样退出整个 App

因此我更常用下面这组操作：

⌘H + ⌘Tab 比 ⌘M 更适合频繁切换 Terminal、浏览器和 IDE，也不需要额外处理最小化窗口的恢复。

需要注意，⌘H 隐藏的是当前 App 的全部窗口，而 ⌘M 只最小化当前窗口。如果需要暂时收起整个 App，优先使用 ⌘H；如果只想收起某一个窗口，再使用 ⌘M。

如何恢复被最小化的窗口

如果已经使用 ⌘M 最小化窗口，可以使用下面两种方式恢复。

使用键盘恢复

  1. 按住 ⌘ Command。
  2. 使用 Tab 选中目标 App。
  3. 在松开 ⌘ 前按住 ⌥ Option。
  4. 松开 ⌘ Command。
