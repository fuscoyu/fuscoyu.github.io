交换机常用命令整理

最近整理交换机配置时，发现很多命令平时都用得上，但分散记忆很容易忘。这里按实际排障和配置的顺序，把常见命令整理成一篇速查笔记。

本文命令以华为 VRP 风格为主，H3C、不同型号或不同系统版本的命令可能略有差异，实际操作前建议先用 ? 或官方文档确认。

1. 进入和退出配置模式

交换机命令一般分两类：

  • display：查看状态，不修改配置。
  • 配置命令：需要先进入 system-view。

排障时优先使用 display 命令确认现状；真正改配置前，建议先备份当前配置。

2. 基本查看类命令

这类命令最常用，适合先确认交换机整体状态。

命令 作用
display current-configuration 查看当前运行配置，类似 running-config
display saved-configuration 查看已保存配置，类似 startup-config
display version 查看系统版本、运行时间、设备型号
display interface brief 查看所有接口简要状态
display interface GigabitEthernet0/0/1 查看指定接口详细信息
display vlan 查看 VLAN 配置
display ip interface brief 查看三层接口 IP 配置
display mac-address 查看 MAC 地址表
display arp 查看 ARP 表
display logbuffer 查看日志缓存
display cpu-usage 查看 CPU 使用率
display memory 查看内存使用情况

6. 配置 Access 端口

Access 端口一般用于接入普通服务器、PC、摄像头等终端设备。

Access 端口的特点是：

  • 只属于一个 VLAN。
  • 端口收到的普通流量默认是不带 VLAN 标签的。
  • 交换机内部会把这些流量归到指定 VLAN。

7. 配置 Trunk 端口

Trunk 端口一般用于交换机之间互联，或者连接需要承载多个 VLAN 的设备，比如上联交换机、虚拟化宿主机。

含义：

  • port link-type trunk：把端口设置为 Trunk 模式。
  • port trunk allow-pass vlan 10 20 30：允许 VLAN 10、20、30 通过。

如果两端都是 Trunk，重点检查两边允许通过的 VLAN 是否一致。

8. Eth-Trunk 和 Trunk 的区别

Trunk 和 Eth-Trunk 很容易混在一起，但它们不是一个东西：

  • Trunk：端口链路类型，用来承载多个 VLAN。
  • Eth-Trunk：链路聚合，把多根物理链路捆成一条逻辑链路。

一个 Eth-Trunk 逻辑接口也可以配置成 Trunk 模式。

示例：把 GigabitEthernet0/0/2 和 GigabitEthernet0/0/3 加入 Eth-Trunk1，并允许 VLAN 10、20、30 通过。

9. 端口安全配置

端口安全可以限制一个端口允许学习的 MAC 地址数量，常用于接入侧防止私接交换机或多设备接入。

示例：限制 GigabitEthernet0/0/1 最多学习 1 个 MAC 地址，并启用 sticky 学习。

含义：

  • port-security enable：启用端口安全。
  • port-security max-mac-count 1：最多允许 1 个 MAC。
  • port-security mac-address sticky：把动态学习到的 MAC 固化为 sticky MAC。

配置前要确认这个端口后面确实只接一个终端，否则可能误伤正常业务。

10. DHCP 服务器配置

交换机作为 DHCP 服务器时，通常不只是创建地址池，还需要：

  1. 开启 DHCP 服务。
  2. 创建地址池。
  3. 配置三层网关接口。
  4. 在接口上启用 DHCP 分配方式。

示例：给 VLAN 10 分配 192.168.10.0/24 地址。

13. 排障思路

交换机排障不要一上来就改配置，可以按这个顺序看：

  1. 看物理链路：display interface brief
  2. 看接口详细状态：display interface GigabitEthernet0/0/1
  3. 看 VLAN：display vlan
  4. 看 MAC 学习：display mac-address
  5. 看 ARP：display arp
  6. 看日志：display logbuffer
  7. 看设备压力：display cpu-usage、display memory

常见问题和方向：

现象 优先检查
接口 Down 网线、光模块、对端端口、shutdown
同 VLAN 不通 Access VLAN、MAC 地址表、终端 IP
跨 VLAN 不通 三层网关、Vlanif、路由、ACL
Trunk 不通 两端 Trunk 模式、允许 VLAN、Native VLAN/PVID
DHCP 拿不到地址 VLAN、Vlanif、地址池、dhcp select global
部分流量不通 ACL、端口安全、日志和丢包计数
