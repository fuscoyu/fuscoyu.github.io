Tailscale 导致 SSH 断连排查

2026-06-25 Network ， Tailscale

在 Linux VM 里启动 Tailscale 后，当前 SSH 连接立刻断开。这个问题看起来像 sshd 异常，但很多时候真正原因是：Tailscale 接收了子网路由，并插入了优先级更高的策略路由，导致 SSH 回包被导向 tailscale0。

重新登录后直接看原始输出：

重点看两处：

  • 5270: from all lookup 52：table 52 排在 main 前面。
  • 192.168.39.0/24 dev tailscale0：SSH 客户端所在网段可能被 Tailscale 接管。

这说明 Tailscale 的 table 52 比系统默认的 main 路由表更早被查询。如果 SSH 客户端所在网段也被 Tailscale 接管，SSH 回程就可能被抢走。

Linux 策略路由里，pref 数值越小，优先级越高。这里 5270 小于 32766，所以会先查 Tailscale 的 table 52，再查 main 表。
